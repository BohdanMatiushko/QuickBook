🔒 Обмеження цілісності (Integrity Constraints)

UNIQUE

  • User.email — унікальна електронна адреса
  • User.username — унікальне ім'я користувача
  • Payment.transaction_id — унікальний ID транзакції
  • Review.appointment_id — один відгук на запис (OneToOne)
  • Payment.appointment_id — одна оплата на запис (OneToOne)
  • ServiceSpecialist(service, specialist) — складний UNIQUE
  • WorkSchedule(specialist, day_of_week) — складний UNIQUE

CHECK

  • Appointment.status ∈ {scheduled, completed, cancelled}
  • Review.rating ∈ [1, 2, 3, 4, 5]
  • Payment.status ∈ {pending, paid, refunded, failed}
  • Payment.payment_method ∈ {cash, card, online}
  • WorkSchedule.day_of_week ∈ [0..6]
  • Notification.notification_type ∈ {reminder, status_change, cancellation, promotion, system}

NOT NULL (критичні поля)

  • User.username — обов'язкове ім'я
  • Appointment.client_id — обов'язковий клієнт
  • Appointment.service_id — обов'язкова послуга
  • Appointment.date — обов'язкова дата
  • Appointment.start_time — обов'язковий час
  • Service.name, Service.price — назва та ціна
  • Payment.amount — обов'язкова сума
  • Notification.recipient_id, title, message
